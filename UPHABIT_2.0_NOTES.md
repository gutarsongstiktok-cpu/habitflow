# UpHabit 2.0 — мотивация

Добавлено поверх рабочей версии:
- XP за выполнение привычек: +10 XP
- XP за выполнение задачи: +20 XP
- бонус за идеальный день: +50 XP
- достижения за первый habit/task, 7-дневную серию, 100/1000 XP
- уровни с прогрессом
- внутренняя валюта «монеты»
- экран прогресса на странице привычек и в профиле
- достижения в профиле
- экспорт включает gamification

Совместимость: старые AppData без поля `gamification` автоматически нормализуются значениями 0 XP / 0 монет / пустые достижения и события.
Backend менять не требуется: gamification хранится внутри существующего JSONB `app_data`.
