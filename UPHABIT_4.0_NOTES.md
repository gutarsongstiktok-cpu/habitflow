# UpHabit 4.0 — MOMENTUM

## Product direction
UpHabit 4.0 focuses on retention and daily momentum rather than adding disconnected screens.

### Added
- Daily Momentum / quest card on the Today dashboard.
- Dynamic daily quest progress from real habits/tasks.
- More actionable AI Coach copy based on current state.
- Analytics insight card with behavior-oriented recommendation.
- Habit rhythm + best streak + financial health/savings rate.
- Shareable progress card using Telegram's share URL.
- Micro-interactions and reduced-motion-friendly CSS transitions.
- Existing local/cloud data model remains backward compatible.

### Important
The AI Coach remains a deterministic in-app coach until an AI API key/backend endpoint is configured. No fake external AI request is made.
