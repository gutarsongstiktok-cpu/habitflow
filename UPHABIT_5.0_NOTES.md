# UpHabit 5.0 — MOMENTUM PRO

## New
- Reward Store with persistent coin spending.
- Daily Challenges UI: perfect day, 3 tasks, 7-day streak.
- Premium hub and demo activation.
- Social sharing hub for Telegram.
- Expanded profile as the product hub.
- Rewards persisted through AppData.

## Compatibility
Existing habits, tasks, wallets, categories, transactions, budgets, goals and gamification data are preserved. `rewards` is backward-compatible via normalization.

## Backend
No required backend migration for this frontend milestone. Real social leaderboards, Telegram friend graph, payments and server-side AI should be connected later through dedicated endpoints.
